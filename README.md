# Week 4 Capstone Project: Internship Selection Prediction

A machine learning project that analyses applicant information and predicts internship selection outcomes using Logistic Regression.

# 1. Objective

To analyse applicant data, identify factors associated with internship selection, and develop a machine learning model to predict selection outcomes.

# 2. Dataset Description

The dataset contains applicant information, including:

- Applicant details and application domains.

- Number of skills listed.

- Portfolio availability.

- Previous hackathon participation.

- Personal statement quality scores.

- Internship selection status.

Some additional applicant characteristics were simulated for this project.

# 3. Methodology

The project followed these steps:

- Data Cleaning: Checked for missing values, duplicates, and inconsistencies.

- Feature Preparation: Created additional features and converted categorical variables into numerical format.

- Model Development: Applied Logistic Regression to predict internship selection outcomes.

- Model Evaluation: Evaluated performance using accuracy, precision, and recall.

# 4. Key Results

The Logistic Regression model achieved the following results:


- Accuracy(84.62%)

- Precision(91.67%)

- Recall(91.67%)

# Interpretation:

- **Accuracy (84.62%):** The model correctly predicted approximately 85% of the test observations.

- **Precision (91.67%):** Most applicants predicted as selected were actually selected.

- **Recall (91.67%):** The model successfully identified most applicants who were actually selected.
